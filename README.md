# Two-stage endpoint-refined pose framework for multi-individual *Artemia* length measurement

Code for the manuscript "A two-stage endpoint-refined pose framework for multi-individual *Artemia* length measurement".

The framework has two stages applied to every detector candidate:

1. **Target-conditioned pose (TCP)**: the candidate box is padded by 15%, highlighted with a yellow box prompt, and passed to a YOLO11s-Pose model that predicts an ordered 15-point midline.
2. **Endpoint refinement (ER)**: a local residual network corrects only the head and tail points within a length-proportional cap; the 13 internal points are unchanged.

Body length is the scaled length of the corrected polyline.

## Running order

1. Prepare the evaluation manifest: `output/baseline_hrnet_20260922_v1/src/prepare.py`.
2. Train the detector, the parent pose model, the prompt-stage model and the endpoint refiner (the four `train_*.py` scripts at the root).
3. Cache detector candidates: `infer_yolo_candidates.py`.
4. Produce TCP/TCP-ER outputs and input interventions: `run_padding_ablation_20260927.py`, `run_fixed_context.py`.
5. Run the baselines in their folders (MMPCF, MMPCF-CS, UNet-MS/SAG, FishKeypoints-HBB).
6. Score: `analyze_saved.py`, `evaluate_unified.py`, `fishkeypoints_hbb_adaptation_20260929/evaluate_candidates.py`, `run_audit.py`.
7. Paper tables and figures: scripts in `analysis/paper/` (`table_metrics.py` before `make_review_figures.py`).

The detector threshold is fixed at 0.001 for all main comparisons. The deployment script `infer_brine_shrimp_endpoint_refined.py` has a default of 0.5; pass the threshold explicitly to reproduce the paper's candidate set. Inference scripts expect a CUDA GPU. Figure scripts load Times New Roman from the system font directory.

## Data and weights

Images, annotations, scale records, model weights and cached predictions are not included in this repository. The scripts expect them at the relative locations they reference (for example `output/baseline_hrnet_20260922_v1/data_v2/manifest.json` and `deployment/endpoint_refined_v1/weights/`). Availability of the data is stated in the manuscript.

## Requirements

See `requirements.txt`. The archived TCP run used Ultralytics 8.4.95 and PyTorch 2.11.0+cu128 with Python 3.13.9.
